# Pedrozilla baseado en firefox

Simplemente es un concepto, y no esta listo.

- `run.bat` / `run.sh`: lanzan el Firefox instalado con perfil propio.
- `instalar.*`: accesos directos + migracion de marcadores 1.x.
- `firefox-profile-skeleton/`, `newtab/`: perfil y pagina de inicio.
- `tools/`: preparar perfil y migrar datos.
- `fork/`: intento de fork compilado (branding, mozconfig, parches).
